01 / LEAD SOURCING / FROM POST

Watch Reel ↗

Build an auditable lead list.

Creates a reviewable Google Sheet from just an ideal customer profile and geography. It sources prospects; it never contacts them.

I want you to find leads for me. Connect to Google Sheets and create a Google Sheet in my Google Drive containing leads in my niche.

Start by asking only:
1. Ideal customer profile
2. Geography, if applicable

You shouldn't need anything else. Use approved public sources, include the source URL for each lead, and do not contact anyone or send outreach. You may use the Chrome connector to help; if I don't have it installed, ask me to install it.

02 / INBOX TRIAGE / FROM POST

Watch Reel ↗

Triage a Gmail inbox without risky automation.

Finds what needs attention, creates reply drafts and a to-do list, then archives only clearly safe messages.

Review my entire current Gmail inbox and continue through every results page until nothing remains unreviewed. Classify each message as Needs Reply, Action Required, Keep in Inbox, or Safe to Archive. Read the thread when necessary to check whether I already replied. Draft responses where I clearly owe one, but never send them. Create one prioritized to-do list with deadlines and source emails. Create and apply matching Gmail labels, and archive only messages that are clearly safe to archive. Never delete, unsubscribe, report spam, or alter account settings. When uncertain, keep the message in my inbox. Finish with counts, drafts created, the to-do list, deadlines, and anything uncertain.

03 / COLD OUTREACH / REBUILT FROM POST

Draft personalized outreach from a lead sheet.

The workflow from my outreach post, rebuilt as a safe draft-first prompt. Review every email before it goes out.

I have a lead list in [Google Sheet / pasted table]. For each row, use only the listed information and the company's public website to write a concise first outreach email.

Rules:
- Personalize only with facts you can verify.
- Make one clear, relevant offer and one low-pressure call to action.
- Never invent results, clients, or familiarity.
- Never send an email, create a campaign, or change Gmail settings.
- Produce drafts only, in batches of [5], with the source facts used for each draft.
- Flag missing information instead of guessing.

Start with the first [5] leads and wait for my approval before creating another batch.

05 / CONTENT RESEARCH / PERSONAL SKILL

Find videos that genuinely outperformed.

Uses channel-relative performance—not just raw views—to find useful YouTube Shorts and long-form ideas.

Find YouTube Shorts and long-form video outliers from the last [X] days about [TOPIC].

Only include a video when it has:
- at least [MINIMUM VIEWS] views
- at least 1x the channel's subscriber count in views
- at least 3x that channel's recent median views for the same format
- at least four comparable recent videos to establish the baseline

Keep Shorts and long-form separate. For every qualifying video, return the title, direct link, views per subscriber, and a one-line note on the hook or format. If no video clears every gate, say so instead of lowering the bar.

06 / CONTENT IDEAS / PERSONAL SKILL

Turn search behavior into content worth making.

Researches concrete questions, not generic “AI” topics, and ranks ideas by demand, proof, and the gap in existing content.

I make [PLATFORM] content for [AUDIENCE]. Find five concrete content opportunities about [TOPIC] in [GEOGRAPHY].

Use Google Trends and current platform search results. Start with specific outcomes, tools, and audience pain points—not generic terms.

For each idea, return:
1. A title or hook
2. The search query or topic
3. Trend evidence and time window
4. The audience problem
5. A simple demo I can actually show
6. A 0–3 score for demand, momentum, specificity, proof, and gap

Separate observed evidence from your inference. Recommend the one I should make first and explain why.

08 / MARKETING / REBUILT FROM POST

Turn a website into a campaign brief.

Based on the workflow in my Google marketing-tool post: pull the brand cues first, then build ideas around one real offer.

Review this website: [URL]

I need a campaign for: [PRODUCT / OFFER / EVENT]

First, extract only visible brand cues: audience, positioning, voice, colors, visual motifs, offers, and proof. Then create:
1. Three campaign angles
2. Five short-form post ideas for the strongest angle
3. A brief for each visual, including on-screen text
4. A two-week publishing sequence

Do not make up brand claims, testimonials, or performance results. Flag anything you could not verify on the site.

09 / MOTION GRAPHICS / PERSONAL SKILL

Plan transcript-timed motion graphics for a Reel.

Turns spoken beats into a 9:16 graphics plan you can build in Remotion or a browser canvas, then cut with talking-head footage.

I have a Reel script or beat list about [TOPIC]. Help me plan transcript-timed full-screen motion graphics for a 9:16 vertical video.

For each beat, return one row with:
1. Script — the exact spoken line or voiceover
2. Visual — layout (`full-screen graphic`, `split-screen graphic + talking head`, or `full talking head`), on-screen text, and motion events timed to the words
3. Sound — music bed if any, SFX triggers, and what visual moment each sound hits

Rules:
- Graphics should be a standalone 9:16 track I can cut with talking-head footage in CapCut
- If source footage exists, note that timing should be checked with ffprobe before final sync
- Flag beats that need a separate graphics master (e.g. Remotion or browser canvas render)
- Do not invent product results, client names, testimonials, or performance stats
- End with the one beat I should build first and why

Start with a compact table: Script | Visual | Sound
